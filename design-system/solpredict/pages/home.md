# Home Page Override Specs

## Layout Design
*   **Hero Billboard:** Segmented solid departure card panel with uppercase, bold display typography (`Share Tech`).
*   **Featured Spotlight:** Large horizontal block highlighting the most active open prediction contract with compact flip countdown indicators.
*   **Platform stats:** Segmented card grids utilising `<SplitFlapText>` to mechanically flip number values on load.
*   **Explorer Grid:** Flight board listing cards with thick borders (`border-[#2D3142]`) and flat YES/NO ratio indicators.

## Custom Features
*   **Watchlist Expiry checker:** Active client effect checking local watchlists, triggering a toast alert warning when any market closes in < 1 hour.
