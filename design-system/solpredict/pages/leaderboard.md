# Leaderboard Page Override Specs

## Layout Design
*   **Rank Ledger:** High-contrast rows showing rank, address details, positions count, win rate, and total volume traded.
*   **Rank badges:** Custom square indicators for top 3 positions matching Crown and Medal themes.

## Custom Features
*   **Rank by Category filter:** Isolates position logs matching a specific category to calculate rankings, letting users compare standing strictly within selected sectors (e.g. "Top Crypto prediction traders").
